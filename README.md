## Зачем это бизнесу

Менеджеры тратят часы на ручной расчёт стоимости в переписке: «а сколько будет
убрать двушку после ремонта с мытьём окон?». Mini App снимает эту рутину —
**клиент считает сам**, видит честную вилку цены и оставляет заявку в один тап.
Бизнес получает не «холодный» вопрос, а готовый лид с параметрами и суммой.

- ⚡️ Цена обновляется вживую при каждом изменении параметров
- 📲 Работает прямо внутри Telegram — без сайтов, звонков и установки приложений
- 🔔 Заявка мгновенно приходит владельцу в Telegram с полным расчётом
- 🗂 Владелец отмечает статус заявки («в работе» / «обработано») одной кнопкой

## Возможности

**Для клиента**
- Выбор типа уборки, площади (слайдер + поле), срочности и доп-услуг
- Прозрачная детализация: из чего складывается цена
- Понятная вилка стоимости «≈ X–Y ₽» и аккуратная форма заявки
- Экран «что дальше»: обещание перезвона и контакт менеджера

**Для владельца**
- Уведомление в Telegram с именем, телефоном, параметрами и итоговой ценой
- Inline-кнопки статуса прямо под заявкой — видно, что уже обработано
- Пометка повторной (исправленной) заявки, чтобы не путать с новой
- Онбординг по `/start` с кнопкой запуска калькулятора

## Как считается цена

```
итог = ставка[тип] × площадь × коэффициент срочности + сумма доп-услуг
далее применяется минимальный заказ; вилка = [итог, итог × 1.2]
```

| Параметр | Значение |
|---|---|
| Поддерживающая / Генеральная / После ремонта | 60 / 120 / 180 ₽ за м² |
| Срочность | обычная ×1.0 · в течение 24 ч ×1.2 |
| Доп-услуги | окна, химчистка дивана/ковра, духовка, холодильник, глажка |
| Минимальный заказ | 2 500 ₽ |

Вся ценовая логика ниши вынесена в один конфиг — **смена ниши = правка одного файла**,
код калькулятора и приёма заявок не меняется.

## Технологии

`Next.js 14 (App Router)` · `TypeScript` · `Tailwind CSS` · `Zod`
· `Telegram WebApp SDK` · `Telegram Bot API` · `Vercel`

Без базы данных, оплаты и авторизации — лёгкий, быстрый MVP.

## Инженерные решения

- **Серверный пересчёт цены.** Бэкенд считает стоимость заново по конфигу и не
  доверяет числам с клиента — цену в уведомлении нельзя подделать.
- **Строгая валидация (Zod).** Тип, срочность и опции проверяются по конфигу,
  телефон — по количеству цифр; мусорные данные отсекаются с понятными ошибками.
- **Проверка подлинности Telegram.** Подпись `initData` валидируется по HMAC-SHA256 —
  подтверждение, что заявка действительно пришла из Telegram.
- **Статусы заявок без базы данных.** Состояние «в работе / обработано» живёт прямо
  в Telegram-сообщении и меняется через webhook по нажатию inline-кнопки.
- **Нативная интеграция с Telegram.** Тема оформления, `MainButton` и `BackButton`
  подхватываются автоматически; вне Telegram приложение работает как обычный сайт.
- **Безопасность секретов.** Токены и ключи — только в переменных окружения,
  в репозитории их нет.
