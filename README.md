# Telegram Mini App калькулятор стоимости

**Telegram Mini App калькулятор стоимости** — портфолио-пример интерактивного калькулятора для бизнеса: клиент сам считает примерную цену услуги, оставляет заявку, а владелец получает её в Telegram уже с параметрами и суммой.

> Это не готовая коробка “купил и забрал”.  
> Это витринный demo-проект: пример системы, которую можно адаптировать под конкретный бизнес, нишу, цены, форму заявки, Telegram-уведомления и процесс обработки лидов.

## Что показывает проект

Проект показывает простой коммерческий сценарий:

1. Клиент открывает Telegram Mini App или web-страницу.
2. Выбирает параметры услуги.
3. Видит примерную стоимость сразу, без переписки с менеджером.
4. Оставляет имя, телефон и комментарий.
5. Владелец получает заявку в Telegram с расчётом.
6. Менеджер может отметить статус заявки прямо в Telegram.

Коротко:

```text
Калькулятор → расчёт цены → форма заявки → Telegram-уведомление → обработка лида
```

## Почему это полезно бизнесу

Во многих услугах клиент сначала спрашивает: “Сколько это будет стоить?”. Менеджер тратит время на уточнения, расчёты и переписку.

Такой калькулятор снимает часть рутины:

- клиент сам вводит параметры;
- цена считается автоматически;
- заявка приходит уже “тёплой”;
- менеджер видит не просто телефон, а контекст заявки;
- бизнес быстрее отвечает и меньше теряет лидов.

В demo используется ниша **клининга**:

## Demo vs production

В этом репозитории проект оформлен как portfolio demo.

**В demo:**

- показана логика калькулятора;
- работает форма заявки;
- есть Telegram integration flow;
- есть mock-режим без секретов;
- нет базы данных;
- нет реальной оплаты;
- нет полноценной CRM.

**Для production-версии под клиента обычно добавляются:**

- реальные цены и бизнес-правила;
- подключение Telegram-бота клиента;
- сохранение заявок в Google Sheets/CRM/БД;
- защита webhook и production env;
- домен;
- аналитика;
- дополнительные сценарии обработки заявок.

## Технически проект демонстрирует

- `Next.js 14` + App Router;
- `TypeScript`;
- `Tailwind CSS`;
- `Zod` validation;
- Telegram Mini App SDK;
- Telegram Bot API;
- серверный пересчёт цены;
- проверку Telegram `initData`;
- webhook для `/start` и статусов заявки;
- Vercel deploy.

## Почему цена пересчитывается на сервере

Клиентский интерфейс показывает расчёт для удобства пользователя, но при отправке заявки сервер считает цену заново по конфигу.

Это важно: пользователь не может подменить сумму в браузере и отправить владельцу “фейковую” цену.
